1. PROJECT OVERVIEW

Create a cute, modern, child-friendly educational web app / responsive learning platform called:
PASTEL STUDYBOX
The platform is designed for children aged 4–12 years old, covering preschool through primary school.
Pastel StudyBox should combine:

* educational games
* interactive quizzes
* printable worksheets
* learning notes
* challenges
* progress tracking
* stars and rewards
* achievement badges
* parent dashboard

The experience should feel like a cute digital learning world, not like a traditional school portal.
The visual identity must be clearly connected to Pastel Shop House.

4. VISUAL STYLE

Create a:
Cute + Cozy + Premium Pastel Educational UI

Use:

Use subtle gradients.
Use soft shadows.
Use large rounded corners.
Use friendly illustrations.
Use plenty of whitespace.

23. RESPONSIVE DESIGN

The application must work beautifully on:

* Mobile
* Tablet
* Desktop

Prioritise tablet and mobile because children may use tablets for learning.
Cards should automatically resize.
Navigation should adapt to screen size.
Do not create horizontal scrolling unless specifically needed.

24. ACCESSIBILITY

Use:

* large buttons
* clear icons
* readable text
* high enough contrast
* simple instructions
* minimal text on children's screens
* visual feedback
* keyboard accessibility where appropriate

Do not rely only on colour to communicate success or failure.

25. ANIMATION

Use subtle, delightful animations.
Examples:

* floating stars
* card hover
* button bounce
* character wave
* progress filling
* badge unlock
* star collection
* correct-answer celebration

Animations must remain smooth and not distract from learning.
Provide reduced-motion support where possible.
